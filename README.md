# Family Library
Family Library is a child-friendly web application built with PHP.

The goal of this project is to help children manage their personal library in a fun and intuitive way.

## Features

- Manage books
- Manage Readers
- Borrow and return books
- View library statistics

## Technologies 

- PHP 8
- HTML5
- CSS3
- JavaScript
- JSON (future data storage)
